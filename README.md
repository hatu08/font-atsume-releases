# フォント集めました

Macに入っているフォントを、和文の見本で探し、比較し、整理するアプリです。

- 対応：macOS 14以降、Appleシリコン・Intel。
- お気に入り・タグ・メモ、書体の分類、フォント比較、見本のPNG書き出し。
- ライト・ダークの切り替えと、アプリ内の更新確認に対応。

## インストール

[最新版のダウンロードページ](https://github.com/hatu08/font-atsume-releases/releases/latest)に添付された **FontAtsume-<版番号>-<ビルド番号>.zip** をダウンロードし、展開した「はじめにお読みください.txt」に沿ってインストールしてください。GitHubが自動生成するSource code ZIPはアプリのインストーラではありません。

現行はチーム試用向けの簡易署名版で、Appleの公証は未実施です。

## アップデート

新しい版の準備ができたら、アプリ内の「更新して再起動」を選びます。お気に入り・タグ・メモはアプリ本体の外に保存され、更新時に引き継がれます。

フォントファイルを配布物に含めたり、移動・削除・有効化・無効化したりする機能はありません。
